# Mini NPU Simulator

## 실행 방법

Python 3.8 이상에서 `python main.py`를 실행한다.
사용자 입력은 1번, `data.json` 일괄 분석은 2번을 선택한다.

## 구현 요약

패턴과 필터의 같은 위치를 반복문으로 곱하고 더해 MAC 점수를 계산한다.
두 점수의 차이가 `1e-9`보다 작으면 `UNDECIDED`로 판정한다.
JSON의 `+`, `cross`, `x` 라벨은 `Cross`, `X`로 정규화한다.

## 결과 리포트

`data.json`의 각 패턴은 키에서 크기 N을 읽고 같은 크기의 필터와 비교한다.
행과 열의 개수가 N과 다르면 해당 케이스만 FAIL로 처리한다.
숫자가 아닌 값과 필수 데이터 누락도 같은 방식으로 FAIL 사유에 남긴다.
라벨을 미리 정규화하므로 `+`와 `Cross`의 표기 차이로 인한 오판정을 막을 수 있다.
부동소수점 계산에서 매우 작은 차이가 나도 epsilon 정책으로 동점 처리한다.
동점 판정은 예상 라벨 Cross/X와 다르므로 FAIL이 되며 요약에 표시된다.
성능 측정은 파일 읽기와 출력을 제외하고 MAC 함수만 10회 실행한다.
N×N 행렬의 각 위치를 한 번씩 방문하므로 곱셈 연산 횟수는 N²이다.
따라서 MAC 함수의 시간 복잡도는 O(N²)이다.
표의 9, 25, 169, 625는 각각 3²3, 5²5, 13²13, 25²25의 연산 횟수이다.
행렬이 커질수록 방문하는 원소가 늘어 평균 연산 시간도 전체적으로 증가한다.
